VAL Match 推广素材使用说明

先发什么
• AstrBot / 机器人社区：横版视频 + QQ 短文案 + 市场链接。需要展开介绍时用 community-post.txt。
• QQ 群图文：share-poster.png + qq-message.txt；感兴趣的人可扫码查看。
• B站 / 电脑端视频：val-match-demo.mp4 + cover.jpg + video-caption.txt。
• 手机竖屏视频：val-match-vertical.mp4 + video-caption.txt。
• README / 社区预览：preview.gif，点击再看完整 MP4。

试用安排
1. 先找 3～5 位有无畏契约观赛群的 AstrBot 群主，帮助其完成第一次赛程与竞猜配置。
2. 收集安装、字体、赛事选择和表情交互的问题；用脱敏反馈改善上手指南。
3. 一周后看新增下载和持续使用反馈，再决定扩展到哪些渠道。

发布节奏
同一社区先发一条完整作品介绍，在该帖中跟进问题与更新。遵守当地作品分享规则。没有收到群主邀请时，不往陌生群投放消息。
不把帖子浏览量、视频播放量或下载次数当成独立活跃用户数。

素材说明
视频 1920×1080 / 1080×1920，30fps，28.8 秒，H.264 + AAC；无需平台额外字体。
内容采用插件原生图形和同款字体、颜色。竞猜昵称、头像和对阵数据为示意，未使用真实群成员数据。
原生图片旁的模拟群聊框与鼠标用于解释交互，并非 QQ 客户端实录。
全场战报为历史赛事样例，比分、选手与地图信息来自原有展示图。
背景音乐与点击声由本项目脚本合成，没有使用第三方音乐采样。
队标、选手等赛事素材权利归相关权利人；QQ 表情图案版权归腾讯，参见 assets/ATTRIBUTION.md。

生成脚本：scripts/build_promo.py
字幕文件：captions-zh.srt
时间线：storyboard.json
