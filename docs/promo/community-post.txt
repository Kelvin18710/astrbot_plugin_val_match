标题：让群友和机器人比比谁更懂瓦｜VAL Match 0.9.0

做了一个适合无畏契约观赛群的 AstrBot 插件，想找几位同样在群里看比赛的群主一起试用。

最想展示的是点选竞猜：每场比赛一张图片，下方两个 QQ 表情代表两支队伍。点一下选赢家，改主意就点另一边，不必组织指令，也不用猜比分。机器人可以独立预测，同样参与排名。

比赛前后也串起来了：
• 赛前：自动发赛程，竞猜紧随其后；支持按每天首场开赛时间提前推送，提前多久可配置。
• 赛中：开赛提醒。
• 赛后：系列赛比分、地图结果、十名选手的完整战报；等当日比赛结束并且战报发送成功，再发积分榜。

积分按群和赛事分别统计。图片榜里有头像、每日赛果、猜中成员和胜负正确率，底部还有连准纪录等荣誉。未参与、未结算的比赛不计入正确率分母。

当前点选适用于 QQ / NapCat；安装在 AstrBot 中使用。基础赛程查询无需额外 API Key，机器人独立预测是可选功能，需要接入模型。开源免费。
