# 第一次用 VAL Match，从一张赛程开始

[← 返回功能与效果展示](../README.md) · [完整配置参考](CONFIGURATION.md)

不用一次配置所有功能。先查到比赛，再把你想要的提醒和竞猜接进群里。

## 先确认能查比赛

安装后，在已接入机器人的群里发送：

```text
/val today
```

有赛程或“当日没有符合条件的比赛”的正常回复，就可以继续。文字查询无需额外 API Key，无需 AI 模型。默认按北京时间展示 S 级赛事。

接着试试图片：

```text
/val s
```

图片需要中文字体。在 **AstrBot 实际运行的环境** 中安装 `fonts-noto-cjk`；Docker 用户要在容器内安装：

```bash
apt-get update
apt-get install -y fonts-noto-cjk
```

## 你想怎么用？

| 使用方式 | 需要配置什么 | 怎么确认 |
| --- | --- | --- |
| 我只想手动查赛程 | 可以直接用；也可选择特别关心赛事 | `/val today`、`/val s` |
| 群里每天自动收到赛程 | 特别关心赛事、每日推送开关、推送时间、每日推送目标 | 检查保存后的设置；需要立即试发时用 `/val push_test` |
| 开赛提醒、赛后战报 | 特别关心赛事、对应提醒开关、特别关心推送目标 | 控制台查看下一场与后台任务，等待实际比赛触发 |
| 群友一起选胜队 | 特别关心赛事、群内竞猜开关、竞猜目标群；QQ / NapCat 还可开启点选胜队 | @机器人说“今日竞猜”，或点竞猜卡片下方的胜队表情 |

`/val push_test` 会立即发送到配置的每日推送目标，请在你希望试发时使用。

## 1. 选喜欢的赛事

打开 **AstrBot → 插件 → VAL Match 详情 → 赛事控制台**。首次使用会先显示「使用指南」；已配置用户仍直接进入赛程时间线，随时可以切回指南。

点击「选我关心的赛事」，页面会定位到设置中的赛事选择区：

1. 输入联赛名称搜索。
2. 勾选需要的赛事，支持多选，顶部会显示已选项目。
3. 没找到当前联赛？点「更新赛事列表」，已选赛事和未保存设置都会保留。

**赛程、竞猜、开赛提醒和战报统一使用特别关心赛事。** 手动查询没选赛事时使用默认等级过滤；竞猜需先选择特别关心赛事。

## 2. 按需要选功能和接收群

在控制台直接勾选群，不需要自己拼群会话字符串。三个目标入口分别决定不同内容发给谁：

| 设置里的群 | 收到的内容 |
| --- | --- |
| 每日推送目标 | 定时赛程；启用附带赛况图后也会收到赛事积分榜 / 晋级图 |
| 特别关心推送目标 | 已开启的开赛提醒、逐图赛果和全场战报 |
| 竞猜目标群 | 群内自然语言竞猜、今日竞猜信息和竞猜积分榜 |

想让同一个群都收到，就在相应入口都选中它。开关和目标群需要一起配置，单独勾选群不会启用对应功能。

群列表为空时，先确认 OneBot 已连接并且机器人已加入群；也可以展开「手动填写会话」。其他平台尚未完成完整验证。

### 推荐的比赛日节奏

推荐按每天首场开赛时间自动安排：

1. 「赛程与竞猜播报」：开启 **启用每日推送**，推送方式选 **首场赛前**，提前分钟数填 **120**，选择每日推送目标。
2. 「群内竞猜」：启用群内竞猜并选择竞猜目标群。
3. 「赛程与竞猜播报」：开启 **每日发送今日竞猜** 与 **今日竞猜紧随赛程发送**。
4. 「积分榜播报」：开启 **比赛结束后自动发送积分榜**，选择赛后积分榜群。

例如首场 12:00 开赛，当天 10:00 发赛程，随后发竞猜。比赛时间变化会重新计算，每天每群发送一次；无比赛不发送。提前时间最多 1440 分钟，最早从比赛当日 00:00 开始，竞猜仍只开放当天比赛。固定时间模式下仍使用原「每日推送时间」。

紧随赛程只对同时接收赛程和竞猜的群生效；只接收竞猜的群仍按「今日竞猜发送时间」发送。赛后积分榜群必须是竞猜目标群的子集。

赛后模式等当天全部登记的竞猜比赛结束、积分结算完成，并且本群已开启的全场战报均确认发送成功后再发送，跨午夜继续等待。没有比赛时不发赛后榜。没有选择赛后模式的竞猜群，仍按定时开关和时间发送积分榜。

## 3. 保存，再试一句

点击设置页顶部 **保存设置**。控制台会应用配置，不必为每项设置反复重载插件。

指南的进度只按 **已保存配置** 统计；改了但没保存，会明确提醒。指南按钮只定位设置和复制示例，不会替你开启推送、发送群消息。

**想让群友直接点选？** QQ / NapCat 接入可在「设置 → 点选胜队」开启功能并选择群。正式使用时，该群也要加入「竞猜目标群」。保存后，每日竞猜每场发送一张 720×300 横向卡片，「摸鱼 / 摸锦鲤」分别对应左右两队；点图片消息下方的对应表情即可参与。可在设置中开启确认回复，或通过“我的竞猜”核对。改选就点另一个胜队表情；取消表情不会撤销竞猜。表情数量不代表有效竞猜人数，机器人预放的表情仅是入口。

需要立即查看卡片，或使用自然语言方式时，回到竞猜目标群，在聊天软件里选中并 @机器人，再输入：

```text
今日竞猜
```

确认今天的队伍与截止时间，再选胜队。下面是假设今日有 EDG 对阵 PRX 的示例，需要换成实际比赛的队名：

```text
我猜 EDG 赢
```

自然语言提交会回复你的名称、预测胜队和截止时间。点选确认可在设置中关闭；关闭后通过“我的竞猜”核对。改主意就再次 @机器人：

```text
把 EDG 那场改成 PRX 赢
```

查询也需要 @机器人，输入 **我的竞猜** 或 **积分榜**。一次报多场或修改多场都可以，把各场队名和胜队用逗号、换行或“然后”分开。

## 可以直接告诉群友的规则

> 每场比赛一张横向卡片，点下方摸鱼或摸锦鲤表情选胜队，不用打字或 @；点另一队可改选，取消表情不撤销。猜中得 2 分，猜错 0 分，开赛前 10 分钟截止。@机器人说“我的竞猜”或“积分榜”查看。

仅支持今日比赛。未开启点选的接入方式仍可 @机器人说“我猜 EDG 赢”，修改可说“把 EDG 那场改成 PRX 赢”。一次报多场时带上各场队名和胜队，用逗号或“然后”分开；逐场反馈，一场失败不影响其他明确有效的竞猜。

「点选成功后发送确认回复」默认开启，测试后可以关闭以减少刷屏。关闭时，成功提交与修改仍保存，失败或封盘仍会提醒，可随时 @机器人说“我的竞猜”核对。

各群、各赛事独立计分，新赛事从 0 分开始。旧赛事的比分记录和积分保留，既有竞猜按提交时的规则结算，新竞猜只计胜负。历史查询可说“冠军赛积分榜”或“冠军赛我的竞猜”。

积分榜以图片发送，上方每行展示两场当天比赛的队标、赛果和猜中成员头像；赛后延迟发榜仍展示原比赛日。排名展示成员头像、近五场命中、积分和胜负正确率，下方「竞猜荣誉榜」展示带头像的连准纪录、命中率之星和参与达人，保留并列者。连准按比赛时间排序，仅统计本人参与且已结算的场次，未参与或未结算不视为猜错。

胜负正确率 = 本赛事猜中胜队场数 / 本人在本赛事参与且已结算场数。未参加、未结算的场次不进分母。机器人同样只猜胜队、同规则计分，群友不能替它改选。

## 卡住时，从这里检查

| 现象 | 先检查 |
| --- | --- |
| 没有赛程 | 今天是否休赛、所选赛事是否仍在举办、时区是否正确 |
| 有赛程但没有可竞猜比赛 | 是否属于特别关心赛事，赛制和时间是否确认，是否已经封盘 |
| @后没响应 | 真实 @组件、群内竞猜开关、竞猜目标群；单纯输入“@机器人”文字不够 |
| 推送没来 | 对应开关、接收群、展示时区和任务状态；开赛提醒跟随数据源实际状态同步 |
| 机器人没有预测 | 机器人参与开关、AstrBot 可用模型，以及竞猜事件里的失败原因 |
| 图片文字缺失 | 字体是否装在 AstrBot 运行环境 / 容器内 |
| 升级后积分在哪里 | 数据目录 `data/plugin_data/astrbot_plugin_val_match/predictions.sqlite3`；请勿删除 |

需要更深入排查时用 `/val debug`，或在控制台展开「系统状态与事件记录」。完整参数、命令与排查步骤见 [配置参考](CONFIGURATION.md)。
